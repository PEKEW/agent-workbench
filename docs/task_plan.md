# 任务计划

## 目标

结合 CLI 的执行能力与网页的阅读、批注和协作能力，建立一个项目内的多 Agent 工作台。

## 阶段

- [x] 建立空项目、规范、需求基线与讨论证据。
- [x] 新建／恢复 semi-harness 项目：保留创建器，打开已有目录后继续工作。
- [ ] 在项目内接入 Codex 新会话，支持网页交互、原生审批、日志、重连与取回控制权。
- [ ] 管理共享任务、批注、引用和人工转发的多 agent 讨论。
- [ ] 按原生能力完善会话恢复与更多运行时适配。
- [ ] 后期考虑代码查看器及 VS Code／Neovim 联动。

## 已确定的约束

单工作台单项目；多 agent 共享目录；人工 diff 与 Git 管理变更；讨论人工转发优先；通用规范与 Claude 专用规则分开；进度摘要、证据和原始日志各自保存。

## 待落实的实现选择

主产品采用 Go 与内嵌静态网页；会话持久化位置、首个 Codex 适配版本在阶段二确定。删除恢复期限与具体引用字段在对应功能规格中确定。
