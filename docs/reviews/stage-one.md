# 阶段一验证记录

## 范围

Go CLI 与本地 HTTP 服务；内嵌 semi-harness 模板；新建或只读打开项目；文档筛选、渲染、原文和刷新；独立 HTML 的隔离 iframe。未实现 agent 会话或批注写入。

## 实现与证据

- 采用 Go 1.27.1 在 macOS arm64 构建；模块最低版本为 Go 1.25，产品无外部 Go 依赖。
- 测试先验证未实现失败，再完成项目、HTTP、CLI 与图读取功能。
- `go test -race ./...`、`go vet ./...`、`go build` 与 Markdown 检查全部通过。
- 浏览器覆盖创建冲突、中文路径新建、已有目录只读、同名文件、原文、外部编辑刷新、重载、恶意 Markdown、缺项、iframe 隔离与窄屏。
- 独立评审发现读取失败后原文按钮可能显示上一文档，已增加浏览器回归并清空失败状态。
- Archify 提交 a21ed05c9e9c910b66cae912e642ad044302720d 生成设计图，validate、deliver、check、browser-check 全部通过；工作台内另外验证主题切换、父页面隔离与网络阻断。

## 评审五问

正确性：目录创建拒绝覆盖，打开不执行脚本；测试覆盖越界、链接、缺项、坏配置、并发绑定与大文件。

设计：项目目录层、HTTP 层、CLI 各有明确职责；单进程单项目，无数据库和注册中心。

复杂度：模板与网页内嵌；图只读取 HTML 成品，生成器不进入运行时。

测试：Go 使用真实临时目录和 HTTP，浏览器使用真实进程、隔离 Chrome 和测试项目；测试脚本与结果保留。

可维护性：规格、启动说明、第三方许可和当前计划均随代码保存。

实际 CLI 新建／打开、生成项目的模板检查和 SIGTERM 退出均通过；打开前后文件 SHA-256 与 Git 暂存／未提交状态一致。冻结讨论快照哈希未改变。入口、阅读、架构图和窄屏截图已实际查看。

## 限制

本轮运行验证覆盖 macOS arm64。其他平台的浏览器打开方式与文件行为尚未实机验证。图片、HTML 原始标签、图内网络请求／弹窗／下载不在当前阅读器支持范围；图的完整导出可通过单独打开原文件使用。项目根目录或 docs 下 Markdown 单文件 2 MiB，独立图同样为 2 MiB。

独立 HTML 允许执行其本地脚本，但受无 same-origin 权限的 sandbox 和独立 CSP 限制；此隔离不能保证任意恶意脚本不会消耗浏览器 CPU。
