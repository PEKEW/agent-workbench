# 会话控制验证

2026-10-07 实施用户要求的删除、执行提醒、授权配置。当前未自动提交 Git，保留既有讨论和未提交修改。

## 行为

Agent 工具栏提供删除。只清理所选工作台状态和事件文件，自有原生进程退出后才移除目录；保留项目、批注、子会话和原生历史。执行、连接、等待请求、有队列或待回写结果时拒绝；断开遗留输入需显式放弃。符号链接拒绝，删除后重启不复活记录。

对话内显示执行中与等待回复，待审批或问题提示需要人工回应；顶部、浏览器标题和页面提醒同步。首次加载旧回合不重复完成通知；提醒不抢输入焦点。

命令授权入口在顶部和 Agent 工具栏。JSON 保存当前项目或指定会话的完整参数前缀，generation 阻止过期覆盖。匹配 thread/turn、项目内 cwd 和简单参数；复杂 shell、展开、重定向、网络专属审批和额外权限保留人工回应。撤销与实际审批写入通过独立 policy RW 锁串行，审批 IO 不锁住全部会话状态。
