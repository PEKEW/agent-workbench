# 会话执行状态与任务要求验证

## 问题

用户无法看到网页会话执行状态，随后指出已在讨论中回复“实现此功能”。核对日志确认该回复已送达讨论会话 KK2M6L5CUTJE6P52RYMNIGSXZO；原任务却是固定的“请阅读这条讨论，独立给出回应或 Rebuttal”，最新要求被放在讨论材料中。Agent 只返回了实现建议，回合已结束，命令授权功能仍未实现。

会话状态此前仅在 Agent 页小字显示，文档批注没有对应状态入口；日志读取错误还能阻止已获取的会话状态渲染。

## 修改

- 顶部跨页面显示执行中、等待响应或没有执行中任务的数量。
- 会话列表和标题区显示状态，讨论会话展示对应文档与引用，批注旁显示各参与会话并可打开。
- 状态在日志读取前更新，日志和讨论读取失败各自报告；会话接口断开明确显示状态未同步。
- 完成状态改为“回合已结束”，避免将模型回合完成理解为功能验收完成。
- 单条交付保留最新用户发言作为主任务，批量要求逐条处理最新要求，实施要求不再由固定 Rebuttal 指令覆盖。
