# 会话清理、交互提醒与命令授权

## 已确认需求

用户要求删除会话、明显显示进行中和等待回复、提供可用授权配置入口。本次在既有 Go、JSON、原生审批和网页上实现，不增加运行时或任务调度系统，不自动提交 Git。

## 会话清理

显式删除仅清理所选工作台会话状态与事件日志，结束该会话自有运行时。项目文件、文档批注、子会话和 Codex 原生历史保留。运行中、等待响应、连接中、有队列或待回写结果时拒绝删除，先结束任务或处理队列。异常断开保留的 ActiveInput 需要在删除确认中显式放弃；仅在自有运行时已结束后允许。受限根目录中拒绝符号链接；删除后重启不能重新列出该记录。

## 交互提醒

对话时间线持续显示进行中／等待 Agent 回复，以及原生审批或问题待回应。顶部汇总、标题、页面标题和批注参与会话同步状态；完成、失败和首次需要回应时显示不抢焦点的页面提醒，可进入对应会话。轮询重载不重复提醒旧回合；不伪造模型进度或百分比。

## 命令授权

顶部与 Agent 工具栏均提供授权配置。用户填写命令前缀，明确选择当前项目全部工作台会话或某个会话，支持保存与撤销。配置以带 generation 的 JSON 保存在项目 .agent-state/sessions/command-authorizations.json，默认空列表，不修改全局 Codex 配置。

工作台仅对已记录、仍待回应的原生 commandExecution/requestApproval 自动发送本次 accept。匹配包含完整参数边界、项目内 cwd、原生 thread/turn 归属及最新授权 generation；保存和撤销对后续审批立即生效。复杂 shell 操作、展开、重定向和不支持的包装器保留人工审批；不自动同意网络专属审批、终端 stdin、文件修改或权限扩张请求。现有 Codex 执行器和原生限制继续适用。

仅支持普通参数和单一 sh/bash/zsh -c/-lc 包装的简单命令。前缀是明确的参数序列，拒绝宽泛 shell 解释器前缀。最多 64 项，每项最多 32 个参数。记录授权规则 ID 与原生审批 ID，服务不执行模型命令。此配置仅控制工作台回应原生审批；Codex 原本无需审批的命令继续执行，外部 CLI 和管理员规则不受该列表更改。

## 验证

Go race 测试验证清理边界、符号链接、重启、规则解析、范围隔离、部分复杂命令拒绝、自动回应、撤销和状态恢复。Chrome 检查入口可见、正在等待／需要响应提醒、授权生效和撤销、删除后列表与磁盘记录消失，保留旧编辑及讨论回归。
