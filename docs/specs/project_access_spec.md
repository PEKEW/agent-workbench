# 阶段一 项目新建与恢复

## 范围

Go 实现 CLI、本地 HTTP 服务、模板初始化和文档读取。静态网页与模板内嵌到可执行文件。一个进程绑定一个项目；打开后不能换绑，打开另一项目需启动另一进程。此阶段提供文档阅读和刷新，不实现 agent 接入、批注写入或终端接管。

## 命令与流程

`agent-workbench` 启动选择页；`agent-workbench open <目录>` 直接打开已有项目；`agent-workbench new --name <名称> <新目录>` 创建后打开。默认自动打开浏览器，`--no-browser` 只打印地址，`--port` 可指定端口，默认使用空闲端口。Ctrl+C 关闭本地服务。

新建目录的父目录必须存在，目标目录必须不存在，包括空目录和符号链接。保留原创建器复制模板与替换参数的行为，以 Go 实现；嵌入固定模板，不联网下载。项目名非空、最多 100 个字符且不得包含控制字符。配置通过 JSON 编码写入，支持引号与中文。

已有目录只读打开。有效 project.json 或 semi-harness 标志文件／目录用于识别；缺项与配置格式问题展示为提示，仍可阅读。完全无关的目录拒绝打开。打开不执行项目脚本、不生成文件、不修改 Git 状态。

## 文件与界面

左侧按项目相对路径列出根目录 Markdown 和 docs 下 Markdown；同名文件保持独立。默认打开 PLAN.md，其次 README.md。显示项目名、根目录、缺项提示，支持过滤、刷新、渲染阅读和原文切换。文档渲染关闭原始 HTML，链接不触发脚本，项目内 Markdown 链接在阅读器打开。

只读取普通 Markdown 文件，不跟随文档符号链接，不读取根目录以外文件。单文档上限 2 MiB；最多 2000 份文档，超出时提示。打开文档时使用受项目根目录约束的文件访问，并再次校验文件类型和大小。文件删除或修改后返回最新结果或明确错误。

## HTTP 接口

接口返回 JSON；错误格式为 error 字符串。GET /api/project 返回项目或 null；POST /api/project 接收 action（new/open）、path、name；GET /api/document?path=项目相对路径 返回 path 与 markdown。无项目时读取文档返回冲突；重复绑定返回冲突；非法路径或输入返回错误。

只监听 127.0.0.1。每次启动生成随机令牌，通过 URL fragment 交给网页；API 请求使用 X-Workbench-Token。拒绝外部 Origin 与无令牌访问，响应禁止缓存。令牌不写入项目，不放进查询参数。服务关闭后 URL 失效。

## 实现布局

cmd/agent-workbench：命令、监听、浏览器启动和退出。
internal/project：创建、识别、文档索引与受限读取；template 为固定模板。
internal/server：HTTP 接口与单项目绑定；web 为网页资源。

Go 模块采用标准库处理文件、HTTP 与 JSON；Markdown 渲染复用经核对的现有页面资源或引入单一渲染依赖，避免自行编写不完整解析器。

## 验收

新建目录内容正确且不覆盖已有文件；中文、引号与空格路径可用；重复打开不能换绑；已有项目打开及阅读前后文件字节与 Git 状态不变；缺项可见；两个 README 路径独立；越界、外部符号链接、伪造网页请求被拒绝；恶意 Markdown 不执行脚本；网页完成新建和打开两种流程。

## 独立图嵌入

用户指定采用 iframe。项目可在 docs/diagrams/ 保存 Archify 独立 HTML 与 JSON 源，网页增加图列表；无图时不显示此入口。GET /api/diagram?path=相对路径 经过同一令牌验证后返回 HTML，网页用 sandbox=allow-scripts 的 iframe srcdoc 显示。图不能访问父页面、弹窗或调用本地接口；不接生成服务、不做双向编辑。生成工具仅供开发时使用，运行工作台不依赖 Node.js。

为支持独立 HTML 的内联脚本与样式，页面 CSP 允许内联资源；Markdown 始终过滤脚本与事件。iframe 在最前方注入独立 CSP，禁止网络、表单和外部脚本；保留本地图的节点交互。图内下载、弹窗或需要联网的功能不在此嵌入版本范围内。
