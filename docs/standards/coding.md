# 编码规范

主产品使用 Go，前端使用 HTML、CSS 和 JavaScript。工程辅助脚本可保留 Python。

- Go 使用 gofmt 格式化；公开 API 写中文职责说明，错误与用户消息使用中文。
- 用普通数据结构和标准库解决当前需求，避免通用框架与无用抽象。
- 所有外部输入在边界验证；打开项目不执行项目脚本，文件访问限制在已绑定项目内。
- 文件创建拒绝覆盖，失败不得删除或改变原有目录；JSON 使用编码器，不拼接字符串。
- 长生命周期资源明确关闭，HTTP 与进程退出使用明确的清理路径。
- 测试使用真实临时目录和 HTTP 请求，重点覆盖覆盖风险、越界读取、并发绑定及坏输入。
- 验证命令：go test -race ./...、go vet ./...、go build ./cmd/agent-workbench。
- JavaScript 使用安全 DOM 操作；Markdown 渲染不得执行项目文档中的脚本。
- 修改设计先更新规格；当前不添加未使用的兼容层。
