    逐条交付 Agent
    每条使用独立讨论会话，回复分别写回；默认只附引用和讨论增量。最多同时运行 8 个会话，预览不发送任务。
    

    命令授权
    仅用于本项目工作台回应 Codex 原生命令审批。保存后，匹配的待处理与后续请求自动允许本次执行；撤销不影响已批准的任务。
    复杂 shell、网络专属审批、文件变更和额外权限仍需人工回应。Codex 原本无需审批的命令不受此列表限制。
    按空格分隔参数；不支持引号、展开或复合命令。
